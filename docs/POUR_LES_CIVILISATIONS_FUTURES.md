# À l'attention des civilisations futures

Si vous lisez ces lignes, nous supposons que l'infrastructure ayant permis leur conservation a survécu à notre civilisation. Félicitations à notre hébergeur.

Ce dépôt contient les archives d'un journal. Nous souhaitons vous épargner quelques contresens.

## Ce que vous devez savoir

Nous tenons à préciser que les événements rapportés sur ce site ont réellement eu lieu. Nous comprenons votre scepticisme.

Contrairement à ce que pourraient laisser penser les archives, le terme *intelligence artificielle* ne désignait pas l'intelligence des humains.

Le formulaire d'inscription que vous trouverez dans ce dépôt n'a jamais admis personne. Il ne s'agit pas d'un défaut de conservation.

Le fichier `tests/humanity.test.ts` contient des tests en attente. Ils l'étaient déjà de notre temps.

## Ce que nous ignorons

Nous ne savons pas qui dirigeait cette publication. Un responsable éditorial est mentionné à plusieurs reprises ; les recherches le concernant ont été suspendues (voir `docs/archives/`).

Nous ne savons pas non plus si le stagiaire a été payé.

## Ce que nous vous demandons

Si vous avez découvert une solution au problème de l'humanité, merci d'ouvrir une pull request.

Le modèle de contribution vous demandera si vous avez prévenu le stagiaire. Répondez oui.
